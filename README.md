# Making Change Game 🛒

A cheerful first-person food shop game that teaches K–3 kids to check their change: pay with bills from your wallet, get bills and coins back, and decide whether the shopkeeper gave you the right amount. The shopkeeper sometimes gets it wrong on purpose — catch him!

## Play

Open `index.html` in any modern browser — no build step, no dependencies. Works on phones and computers.

## Deploy

This is a single static file, ready for Vercel's free tier: import this repo in Vercel and deploy. No build command needed.
